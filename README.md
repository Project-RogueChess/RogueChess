# OCM

## 주요 스크립트 내용

### DataManager
* 플레이어가 가지고 있을 체력, 골드, 경험치 등의 데이터를 가지고 있음
* 해당 데이터를 다른 스크립트에서 값을 수정할 수 있게 구성
### InventoryManager
* 생성될 때 데이터들을 받아서 인벤토리 슬롯에 데이터를 주입하는 방식
### CSV파일
* 아이템의 데이터를 엑셀파일에서 가지고 있음
* 기물들의 데이터를 엑셀파일에서 가지고 있음
* 위의 데이터들을 여러 스크립트에 리스트나 배열형태로 값을 받음
### Pieces
* 상점에서 데이터들을 받아서 생성할 때 기물들에게 데이터를 넣음
* 
### Synergy
* InvSpawnManager스크립트를 이용해서 타일을 탐색한 뒤 해당 기물들의 정보를 받아서 시너지 있는지 확인
